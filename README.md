# orla-assets

Public hosting for Orla's social media creative assets. Buffer (and other
schedulers) fetch media by URL only, so every approved card is published
here before scheduling. Files land here ONLY after the full approval chain:
producer QC → Donna's release review → TJ's sign-off in the ClaudeOS queue.

Everything in this repo is content approved for public social posts —
nothing sensitive lives here by design.

URL pattern: https://raw.githubusercontent.com/vdburger1991/orla-assets/main/<batch>/<file>
